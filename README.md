#KrishiSuraksha 

KrishiSuraksha is an offline agricultural vehicle safety system designed to improve operator safty in rural farming environments.

#FEATURES
- Real-time vehicle safety monitoring
- Rollover Risk Detection
- Terrain risk assessment
- Collision/obstacle detection
- Machine/sensor monitoring
- Camera-based vision processing
- Risk score generation
- Local dashboard for displaying safety information
- Designed to operate without dependence on external internet connectivity

#HARDWARE
- Raspberry Pi 4
- Camera Module
- Sensor for vehicle monitoring
- Additional safety monitoring hardware

#SOFTWARE
- Python
- OpenCV
- Streamlit
- Raspberry Pi
- Git/GitHub
- Anaconda
